# ДЗ 1. Анализ и предобработка продаж

Данные - [Online Retail](https://archive.ics.uci.edu/dataset/352/online+retail). Выбран товар **47566**. Показатель продаж - сумма `Quantity` с учетом возвратов. Рассмотрены дневная, недельная и месячная агрегации: 372, 54 и 13 наблюдений соответственно.

В ноутбуке `hw1.ipynb` выполнены проверка качества данных, описательный анализ, декомпозиции STL/MSTL и классическим методом, анализ ACF и периодограммы, проверки ADF/KPSS и сравнение преобразований. Основные операции оформлены в функции.  

## Основные результаты

- **Качество данных.** В дневном ряду 69 дней без операций по всем товарам заполнены нулями (дни, для которых продаж нет по всему магазину - предположительно, это выходные и праздничные дни), еще 7 пропусков - медианой 22. Один недельный пропуск заполнен нулем (попал на рождественские праздники), месячных пропусков нет. Возвраты и крупные значения сохранены. Агрегации предобрабатываются отдельно, поэтому заполнение дневных пропусков не пересчитывает недельные и месячные суммы.
- **Уровень и разброс.** Продажи растут к весне–лету 2011 года, затем снижаются. Распределение имеет правый хвост. Разброс неоднороден и выше в дни, когда больше продаж.
- **Сезонность.** На дневной частоте ACF и периодограмма поддерживают цикл 7 дней, цикл в 31 день не подтвердился. Для агрегации по неделям нашелся цикл длины 4.5. Циклов по месяцам не нашлось.
- **Стационарность по дням.** Исходный ряд нестационарен. Рассмотренные преобразования стабилизируют скользящее среднее, но разброс остается непостоянным. В итоге не удалось подобрать преобразование, которое приводит ряд к стационарному виду. 
- **Стационарность по неделям.** Исходный ряд нестационарен. Преобразование вариант «обычная разность → логарифмирование с сохранением знака» приводит ряд с стационарному виду, что подтверждается тестами и диагностикой. 
- **Стационарность по месяцам.** Выбраны два преобразования: удаление тренда и логарифмирование с сохранением знака. Для них тесты поддерживают стационарность. Вообще для короткого ряда сложно судить о стационарности.
